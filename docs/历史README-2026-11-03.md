## 当前固定参数

| 项目 | 设置 |
| --- | --- |
| 抽帧 | 按视频时长均匀抽取，最多 100 张 |
| 图片尺寸 | 长边不超过 1024，保留比例，不放大小图 |
| 相机 | 同一镜头、SIMPLE_RADIAL 相机模型 |
| 特征 | SIFT 峰值阈值 0.002，仿射形状估计和 domain size pooling |
| 匹配 | 全组合匹配并开启 guided matching，连接绕拍首尾视角 |
| COLMAP 特征和匹配 | CPU，降低对不同二进制 GPU 支持的依赖 |
| 默认训练器 | Brush 0.3.0，免编译，Vulkan GPU 训练 |
| 训练 | 7000 次，SH degree 2，随机种子 42 |
| Brush 增密 | 4000 次后停止增长，间隔 200，梯度阈值 0.00004，上限 50 万高斯 |
| 质量门槛 | 至少 30 张抽帧；最佳模型定位至少 75% 图片且存在三维点 |

这套配置已在本机 RTX 4060 Laptop 8GB 上跑通一段 720×1280、31.77 秒的真实椅子视频，不能保证适用于所有素材。最初的 OPENCV/default SIFT 配置只定位 34/100 张；针对该素材弱纹理的恢复设置成功定位 100/100 张，旧尝试保留在 `runs/furniture-e8534dc6d113b15f`。本阶段不自动分割家具、恢复真实尺寸、输出网格或完成 AR；定位率达标也不代表家具所有角度都完整。

## 环境配置

编排脚本只用 Python 标准库。当前使用 `D:/Python/python.exe`（3.13.2）；免安装工具均放在项目 `tools/` 中，不修改系统 PATH。**当前默认 Brush 路线不需要安装 CUDA Toolkit、Visual Studio C++ 或 PyTorch 扩展。** Brush 的训练算法和参数与 Graphdeco 原版不同，二者均采用 3D Gaussian Splatting 表示。

已下载并通过发布方 SHA256 校验：

- [FFmpeg 9.0.2 essentials](https://github.com/GyanD/codexffmpeg/releases/tag/9.0.2)：`60f467265b1e312373dbcd92200c2618a74850f98d3d078e94296bb3fa2047ba`
- [COLMAP 4.2.1 Windows nocuda](https://github.com/colmap/colmap/releases/tag/4.2.1)：`c493d88cb4a43f21afba42cb55bf786e5434a0420e73db0ba1454c5d8b3686ae`
- [Brush 0.3.0 Windows](https://github.com/ArthurBrussee/brush/releases/tag/v0.3.0)：`b68e3e9cf052d51bf3ee30776fa5a364de7f2ba13b58443128ff797bb7bcfcd6`

下载包保存在 `tools/downloads/`，许可证随工具保留。`tools.local.json` 已填写实际路径；迁移到其他电脑时，需准备同样的工具目录和 Python。Windows 官方 COLMAP 包的 `plugins/` 和 `bin/` 会由脚本配置到子进程环境。

Windows JSON 路径推荐使用 `/`，避免反斜杠转义，例如：

```json
{
  "ffmpeg": "tools/ffmpeg/ffmpeg-9.0.2-essentials_build/bin/ffmpeg.exe",
  "ffprobe": "tools/ffmpeg/ffmpeg-9.0.2-essentials_build/bin/ffprobe.exe",
  "colmap": "tools/colmap/bin/colmap.exe",
  "trainer": "brush",
  "brush": "tools/brush/brush_app.exe"
}
```

工具配置中的相对路径以本项目目录为基准；命令行视频和输出路径以终端当前目录为基准。脚本针对 Brush 0.3.0 的小 JPEG 读取问题，在去畸变训练图片不足 16387 字节时追加零填充；原视频和原始抽帧不受影响，解码像素不变。

保留可选的 Graphdeco 后端供已有可用环境使用：设置 `"trainer": "graphdeco"`、`gs_repo` 和 `training_python`。该后端仍需按其官方文档准备 CUDA/C++ 扩展，当前未配置或验证，也不是用户必须执行的步骤。仓库获取方式：

```powershell
git clone https://github.com/graphdeco-inria/gaussian-splatting.git third_party/gaussian-splatting
git -C third_party/gaussian-splatting submodule update --init --recursive submodules/diff-gaussian-rasterization submodules/simple-knn submodules/fused-ssim
```

Graphdeco 后端使用原有增密参数：3000 步停止、间隔 200、阈值 0.0005，并使用 CPU 存放图片。与 Brush 的配置不能直接等同。

## 运行

先检查环境：

```powershell
python reconstruct.py doctor --report environment-report.json
```

报告检查外部工具能否执行。Brush 模式只检查可执行程序版本，不能单独证明 GPU 训练可用；Graphdeco 模式检查 CUDA 扩展和 CUDA 张量操作。全部就绪返回 0；存在缺项返回 2。

准备好视频后，完整运行：

```powershell
python reconstruct.py run --video "input/chair.mp4" --output "runs/chair-001"
```

第一次可先检查抽帧，再继续相机定位，最后训练：

```powershell
python reconstruct.py run --video "input/chair.mp4" --output "runs/chair-001" --stop-after frames
python reconstruct.py run --video "input/chair.mp4" --output "runs/chair-001" --resume --stop-after colmap
python reconstruct.py run --video "input/chair.mp4" --output "runs/chair-001" --resume
```

`--resume` 跳过已成功完成的阶段。失败阶段会创建新的工作目录并从该阶段开始重跑，**不支持恢复训练迭代中间状态**。视频内容、固定参数或训练器变化时会拒绝继续，须使用新的输出目录。脚本不会清空已有目录；旧日志与失败尝试保留以供诊断。

一键入口自动使用 `input/` 中最新的视频，并根据视频内容、固定参数和训练器生成结果目录；同一任务自动续跑。已完成任务会直接检查产物并结束。

非默认工具配置放在子命令之前：

```powershell
python reconstruct.py --tools "my-tools.json" doctor
```

## 输出与检查

```text
runs/chair-001/
  frames/                  原始抽帧，先人工确认清晰度和视角覆盖
  dataset/images/          去畸变图片
  dataset/sparse/0/         3DGS 需要的 COLMAP 相机和稀疏点
  model.ply                仅在训练成功并通过高斯属性检查后导出
  run.json                 参数、视频哈希、状态、阶段耗时和模型统计
  work/<attempt>/          每次尝试的日志、COLMAP 数据库与训练原始输出
```

定位率不足会停止训练，优先检查是否存在运动模糊、弱纹理、变焦、缺少视角重叠或分裂成多个模型。`status=ready` 表示仅完成指定中间阶段；只有最终高斯 PLY 通过检查后才会标记 `completed`。

训练失败时查看 `training.log`；显存不足先关闭其他 GPU 程序，再评估是否需要调整固定参数和创建新实验。退出或中断会保留记录；进程被强制杀死可能留下 `.run.lock`，只有确认该任务不再运行后才可手动移除这个文件。

## 第一件家具怎么拍

- 先选纹理明显、非透明、少反光的椅子或凳子，家具保持不动。
- 拍摄约 45–90 秒，缓慢绕拍完整一圈，并覆盖稍高和稍低的视角。
- 使用同一镜头和固定焦段，不切换镜头、不变焦、不暂停拼接；尽量保持曝光稳定。
- 保持家具完整可见，保留一些有纹理的静态背景帮助定位，不必把背景处理成纯白。
- 光线稳定且充足，避免运动模糊、行人和宠物进入画面。
- 未拍到的底部、背面不会因为使用现成算法就自动得到可信还原。

## 验证代码

```powershell
python -m unittest discover -s tests -v
```

模拟工具覆盖：带空格/中文/特殊字符的路径、最佳稀疏模型选择、旧/新 COLMAP 参数、定位不足、工具失败、失败续跑、已有文件保护、运行锁、产物丢失、缺失训练结果和截断 PLY。模拟测试不生成真实家具模型。

`python smoke_check.py` 会调用真实工具，在新的 `runs/environment-smoke-*` 文件夹生成测试数据、运行短程 GPU 训练和视频/COLMAP 检查，并写入 `smoke-report.json`。仅此开发检查需要 numpy、Pillow（本机已有）；正常重建入口不依赖它们。

`python inspect_result.py runs/furniture-470cc7e52c525dbe` 使用 Brush 原生渲染器回看四个原拍摄视角。Brush 0.3.0 缺少纯渲染 CLI，因此将 PLY 作为初始化、使用近零/零学习率和关闭噪声进行一步检查；导出的所有 Gaussian 字段须与原模型在绝对误差 `1e-6` 内一致，再接受渲染图。该脚本需要 numpy；本次最大字段差为 `2.384e-7`（四元数归一化），位置、尺度和透明度未变。检查图片来自训练视角，不能作为独立测试集或新视角质量指标。

## 单独提取本次椅子

双击 `预览纯椅子模型.cmd` 查看 `runs/furniture-470cc7e52c525dbe/chair.ply`。原来的 `预览椅子模型.cmd` 继续打开包含房间的原模型，二者可以比较。

`extract_chair.py` 使用本次视频四幅去畸变画面的**人工轮廓标注**（`chair_masks.json`），结合 COLMAP 位姿，把 Gaussian 中心投影到轮廓中；至少三幅图支持且所有可见视角均通过才保留。它不是任意家具都可直接使用的自动语义分割工具。运行会创建新的 `extraction/<timestamp>/`，不会覆盖原模型。正式 `chair.ply` 是已通过渲染检查的结果，重新提取后仍需检查再发布。

导出保留完整 Gaussian 属性，逐字节验证保留记录与原模型一致，并校验原模型 SHA256 未变。针对 Brush 0.3.0 的末尾 SH 读回问题，数量向下对齐到 4 的倍数，仅移除至多 3 个低透明度高斯；本次移除 1 个。四个原视角的原生渲染已检查；仍有椅脚晕影和边缘模糊，未验证所有自由视角或未拍摄的底面。裁掉背景后，不应把与原始整幅房间照片比较的 PSNR/SSIM 当作椅子质量分数。
