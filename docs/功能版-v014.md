# 家居重建 v0.14.0 功能版

2026-11-17，versionCode 23，包名仍为 com.furniture.chairdemo。此轮只补功能，保持既有训练参数、原生训练库、模型资产和遮挡着色器；下一版集中 UI/手感，后续再优化重建质量。

## 本版新增

1. 电脑页面显示本机连接二维码；App 内“扫码连接电脑”使用内置相机与 ZXing 解码，不需另装扫码 App。扫描后显示目标地址，由用户确认后配对。手动地址和 8 位码保留。二维码图像和连接页面仅对电脑本机开放，不把访问令牌放进二维码。
2. “检测连接”检查服务健康、身份和授权，区分未启动/网络不通/授权失效。电脑改 IP、重新配对同一服务时保留任务记录。
3. “电脑任务历史”列出当前配对电脑最近100项任务，可切换到完成、失败、取消或处理中任务。进入完成任务会下载或复用已有模型；原始扫描在本手机时可以重新生成。原始照片在另一台手机时给出明确提示。
4. “继续查询 / 重试下载”；查询时临时网络错误会有限次数重试，断网不重复启动电脑训练。导入后的结果按电脑任务身份复用，即使本机映射丢失也会寻找已有有效结果。校验失败时清理本次下载的暂存目录，保留原模型。
5. 房间中保存家具组合，首页“已保存房间布局”可读取、重命名和删除。保存独立家具实例的模型身份、相对姿态、长宽高、接地偏移、尺寸模式和锁定状态，同一个模型可在布局中出现多次。
6. 恢复时重新点击已识别地面，指定整组家具的参考位置；支持整组左右旋转15°，之后仍可逐件选中和调整。离开有摆放的房间时提示保存/直接返回/继续摆放。
7. 被保存布局引用的模型不能直接删除，先删除相应布局；删除布局只删除摆放记录，不删除模型。

## 使用与限制

- 新增功能需要同时使用本版电脑服务。若旧服务仍在运行，先确认没有任务，停止旧服务后再用“启动电脑重建服务.cmd”启动。重复点击启动器不会自动热更新已运行的旧进程。
- 本机已在 tools/server-python 安装 qrcode 8.2；迁移电脑按 requirements-server.txt 安装。APK 内置 ZXing 3.5.3，构建时检查 SHA256，许可证随 APK 保留。
- 恢复布局是人工选择参考位置后的相对布局恢复，不是自动识别旧房间，也不是跨会话持久化 ARCore Anchor。选择参考位置后须检查整组朝向与实际房间一致。
- 单个布局1至20件家具；恢复时总高斯数上限50万，超过时拒绝加载，不承诺所有手机都能流畅显示该上限。
- “任务恢复”是继续查询电脑任务或重试下载；电脑服务重启后未完成训练仍标记中断，不是任意迭代断点续训，也未实现上传字节断点续传。电脑同一时间只处理一个任务。
- 完成的电脑任务即使原始扫描不在当前手机也可下载查看；重新训练需要原采集手机仍有该扫描。
- 本版未增加商家少图生成、公网服务、云 API 或自动家具语义分割。采集、裁剪、尺寸校准、手机本地训练及 AR 多家具沿用原有功能。

## 验证方法

- Python 协议测试：临时服务和模拟工作器，覆盖鉴权、二维码仅本机可见、任务历史、上传校验/路径、单任务取消、幂等和独占监听。不冒充真实 GPU 训练。
- Android FunctionTests：开发模拟器，验证二维码编解码/限制、布局写盘重读/改名删除、旋转参考下相对位置、独立实例尺寸、引用保护、非法数据拒绝。使用合成姿态，不能代替真实平面点击和 Anchor 跟踪。
- Android NetworkFunctionTests：开发模拟器与仅绑定127.0.0.1的隔离服务，验证真实 HTTP 配对、连接检测、任务历史、现成高斯 PLY 下载导入、重复查询/映射丢失恢复、哈希失败保护。不重新训练模型。
- 小米 17 Pro 上已核对安装包版本及 SHA256，确认 App 可启动、可访问电脑服务。用户完成相机扫码配对，电脑收到配对请求并返回 HTTP 200。真机任务历史显示已完成、失败、取消记录，已从完成任务打开 44,493 个高斯的已有模型。房间布局放置恢复、深度遮挡和物理尺度待真机验证。开发模拟器使用 GLESDynamicVersion 和 host GPU。

最终结果及 APK 哈希见 dist/mobile-functions-v014/verification.json；原生后端 SHA256 仍为928e4882179de55e64a17b8e8b344741447ed6504fce231860ef942be065e017。

## 代码

- PairScannerActivity / PairingCode：扫码和严格解析。
- ComputerActivity：连接检测、任务历史、查询重试、下载恢复。
- RoomLayoutStore / RoomLayouts / RoomScene：布局文件、管理入口、相对姿态和整组恢复。
- LibraryStore：布局引用删除保护。
- desktop-server/server.py：本机二维码及带鉴权的任务历史。
- build.py：固定 ZXing 依赖与许可证打包。

第三方参考：[ZXing 3.5.3 官方实现](https://github.com/zxing/zxing/tree/zxing-3.5.3)、[python-qrcode 官方项目](https://github.com/lincolnloop/python-qrcode)。二维码功能分别使用其解码和生成实现，未声称自行发明二维码算法。
