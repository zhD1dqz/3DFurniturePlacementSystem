## 用户入口

安装 `../dist/ChairPreview.apk`，桌面名称「我的椅子」。内置用户实拍重建的 9880 个高斯，近似总高 1 米。单指拖动旋转，双指缩放，重置恢复视角。普通预览离线运行、不申请相机权限。

点「设置长宽高」输入厘米数：长=前后深度、宽=左右宽度、高=总高。默认宽深来自重建估计，需实测替换；可分别按三轴匹配（会改变比例），或勾选只按高度等比缩放。设置会保存，AR 使用米制尺寸和相机投影显示，不靠手势估计比例。

点「放进房间」后确认尺寸、展示 AR 服务说明、请求相机权限，并检测 AR 服务。支持时扫描水平地面，点击平面放置后自动锁定，绕着查看不会误触移动、旋转或缩放。主动解锁后可点击重放和拖动旋转，AR 中双指也不会改变实物尺寸；修改尺寸需解锁后进入设置。返回按钮恢复普通预览。相机图像、传感器由 ARCore 服务处理，App 未实现视频上传，没有网络权限。服务安装、授权或设备支持有问题时保留普通预览。

## v0.2：深度遮挡

运行时检测 `Session.isDepthModeSupported(AUTOMATIC)`，支持则启用 Depth API。逐帧读取 `acquireDepthImage16Bits()`，按 rowStride/pixelStride 复制毫米深度并及时关闭图像，以 R16UI 整数纹理上传。使用 ARCore 的屏幕到 TEXTURE_NORMALIZED 变换映射深度像素；片元比较真实场景深度与高斯中心的相机 Z 深度，前方实物遮住虚拟椅子。无效/太近/太远的深度不遮挡；缺少当前帧深度时不复用旧图，并提示继续扫描。

遮挡是深度估计结果，边缘、透明反光物体、动态物体和弱纹理可能误差较大；单个高斯使用中心深度近似，其椭球内并非精确表面深度。当前尺寸也使用高斯中心的稳健包围范围，渲染尾部可能超出；单目重建和 AR 追踪均有误差，不作为精密测量。ARCore 深度实现依据官方指南：https://developers.google.com/ar/develop/java/depth/developer-guide 。

原始 PLY 字段未改。打包时将位置和完整协方差转换到米制坐标，保留 degree-2 SH 颜色系数；渲染时将视线转回原始坐标计算 SH。使用屏幕空间协方差投影、3σ 椭圆、CPU 深度排序与预乘透明度混合。不是点云占位图，也不是网格。脚边晕影、部分视角模糊继承自原模型。

## 构建

本机已存在 `D:/Android SDK`（build-tools 36.0.0、android-37.0 android.jar）和 `D:/Android Studio/jbr`。ARCore AAR 来源：

https://dl.google.com/dl/android/maven2/com/google/ar/core/1.48.0/core-1.48.0.aar

AAR SHA256：`219afa51796eb2ff12ce97706480ce5cf56d708eff68653ec0239536a722c265`。解压到 `../tools/arcore-1.48.0/` 后执行：

```powershell
& 'D:/Python/python.exe' android-app/build.py
```

构建脚本校验源模型哈希、全部协方差正定性、缩放后协方差迹、数值有限性和标定高度；编译资源/Java、D8 转换、打包各 ABI、16KB ZIP 对齐、本地测试证书签名并验证。每次构建保留独立日志。测试签名证书仅供本地安装，不用于正式发布。最低 Android 7.0，target API 35，要求 OpenGL ES 3.0。

ARCore 依照其分发条款使用：https://developers.google.com/ar/develop/terms 。权限与 AR Optional 配置依据：https://developers.google.com/ar/develop/java/enable-arcore 。AR 服务隐私说明：https://developers.google.com/ar/develop/privacy-requirements 。这些均不是本项目作者自行实现的定位服务。
